# Exemplos históricos e configuração proposta

Arquivos deste diretório são ilustrativos ou de laboratório; não são planos
reais aprovados. Não usar credenciais, documentos pessoais ou dados de clientes.

**Revisão documental de requisitos — 22/10/2026:**

- `regras.exemplo.json` preserva hipóteses iniciais, agora superadas: centavo por
  unidade e prazos judiciais não devem compor o seletor atual do Excel.
- `condominios.exemplo.json` contém booleanos históricos de cadastro antecipado;
  não selecionam o modo universal A/B de novos processamentos.
- `laboratorio_pacote.json` documenta somente o laboratório sintético histórico,
  preservado com seus testes. Não aplicar suas políticas aos dados reais.

A proposta atual é
[`proposta_configuracao_4_3B.revisada.json`](../examples/fase4/proposta_configuracao_4_3B.revisada.json),
**não executável**. A [matriz revisada](../docs/MATRIZ_NEGOCIO_PRELIMINAR_8_REGRAS.md)
e as [decisões](../docs/ATUALIZACAO_REQUISITOS_EXTRAJUDICIAL_FASE4_3B.md) distinguem
requisitos definidos de planos, atestos e implementação ainda pendentes.
Arquivos históricos não foram migrados, ativados ou reescritos nesta revisão.
